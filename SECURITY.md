# Security Policy

## Supported Versions

The latest version and active development branches receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability:

1. **Do NOT open a public issue.**
2. Please report security issues privately via GitHub's [Private Vulnerability Reporting](https://github.com/AdnanGhani07/nextjs-blog-website/security/advisories/new) feature or email the maintainer directly.
3. Include detailed steps to reproduce the vulnerability, along with potential impact.
4. We will acknowledge receipt of your report within 48-72 hours and provide an estimated timeline for a patch.

Thank you for helping keep our project secure!
